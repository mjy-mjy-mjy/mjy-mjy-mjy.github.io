# Changelog

## 0.1.0 — 2026-07-24

首次建立“沐简博客发布”仓库内 Skill。

### 新增

- 选题、初稿、预览、发布、完整执行和改进六种运行模式；
- 博客定位、文章格式和资源目录说明；
- 第三人称为主、少量第一人称的写作规范；
- SVG、氛围插图、Mermaid 与 HTML/CSS 卡片的选择规则；
- 分支、提交、PR、CI、合并和部署状态规范；
- 《Prompt、Skill 和 MCP》文章生产过程的首次复盘；
- Markdown 文章模板；
- 独立 HTML 预览壳；
- Pull Request 模板；
- Front Matter、permalink、标签和占位符校验脚本；
- 图片路径、文章专属目录和替代文本校验脚本；
- 可直接复制使用的调用语示例。

### 默认约束

- 不直接向 `main` 提交；
- 不自动合并 Pull Request；
- 发布前等待 `npm test` 得到明确结果；
- 不把单篇文章的临时要求自动升级为永久规范。
